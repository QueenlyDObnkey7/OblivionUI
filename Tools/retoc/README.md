# retoc build prerequisite

For asset packaging, install retoc 0.1.5 locally as `Tools/retoc/retoc.exe`, or pass `-RetocPath` to BUILD.ps1. Obtain retoc from the trumank/retoc project on GitHub. Keep any runtime dependencies required by that release alongside it according to its instructions. Engine tools, third-party executables and proprietary compression DLLs are not bundled here. The prebuilt mod in dist does not require retoc.
