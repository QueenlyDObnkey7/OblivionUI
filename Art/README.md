# Artwork provenance

BookBackground.png is a blank parchment, leather and brass panel generated from a user-supplied Oblivion Remastered inventory screenshot as a visual reference. The original generated artwork is preserved in BookBackground-original.png. The included clean_book_alpha.py removes the painted checkerboard outside the silhouette using an antialiased alpha mask; it requires Python and Pillow.

NotificationParchment.png is separately generated blank horizontal parchment with real transparent torn edges. Version 0.3.2 uses this texture for notifications, rather than cropping the book background. UI words, controls and game interactions are rendered separately.

Kingthings Petrock is provided unchanged under the EULA in ThirdParty/Kingthings. Unreal source assets corresponding to the artwork are included in Content. No commercial game screenshots are included in this folder.
